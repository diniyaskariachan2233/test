# Modern Website Starter

A clean, professional, dark-mode-ready website starter kit.

## Files
- `index.html` — Main page
- `css/` — Modular stylesheets (variables, typography, layout, components)
- `js/` — Scroll reveal, dark mode toggle, form handling

## Usage
1. Clone or download this repo
2. Open `index.html` in your browser — no build step needed
3. Customise colors in `css/variables.css`
4. Edit content in `index.html`

## Features
- Dark mode with system preference detection
- Scroll-triggered reveal animations
- Responsive grid layout
- Accessible form with validation states
